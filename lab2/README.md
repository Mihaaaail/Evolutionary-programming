# Лабораторная № 2

Вариант 10: план дежурств на неделю, 21 смена и восемь сотрудников.
Самостоятельно реализованы дискретные операторы, штрафы и восстановление допустимости.

Установка дополнительных библиотек не требуется. Выполняйте команды из корня проекта:

```powershell
python -m lab2.run
python -m lab2.run --config lab2/config.json --data lab2/data.json --output lab2/results
```

Входные данные приложены в [data.json](data.json). Если указанный файл отсутствует,
он создаётся по `data_seed`. Имеющийся файл не перезаписывается. Для другого состояния
генерации задайте другую конфигурацию и новый путь к данным.

По 20 запусков: ремонт с переназначением, штрафы с переназначением, ремонт с обменом,
случайный допустимый поиск. В каждом запуске ровно 3000 оценок. Дополнительно
сохраняется результат жадной эвристики.

Анализ в [REPORT.md](REPORT.md); параметры в [config.json](config.json).
В `results/` находятся итоговые и поколенные CSV, четыре графика серий, сравнение,
лучшие векторы назначений, предметная таблица расписания, примеры допустимости,
статистика и описание среды выполнения.

Повторный запуск заменяет результаты и отчёт. Отчёт создаётся в родительской папке
результатов, поэтому для отдельного опыта используйте отдельную родительскую папку.
