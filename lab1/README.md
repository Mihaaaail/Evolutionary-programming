# Лабораторная № 1

Вариант 10: функция Михалевича, девять вещественных координат в [0, π].
Реализованы турнирный отбор, BLX-α, гауссовская мутация, отражение границ и элитизм.

Запуск из корня репозитория, дополнительные библиотеки не нужны:

```powershell
python -m lab1.run
python -m lab1.run --config lab1/config.json --output lab1/results
```

Каждый из двух ГА и случайная выборка выполняют по 20 запусков с бюджетом 12000.
Параметры в [config.json](config.json), анализ в [REPORT.md](REPORT.md).
Начальное состояние генератора задаётся параметром `first_seed`; следующие запуски
получают последовательные различные значения. Все результаты сохраняются в `results/`.
При повторном запуске файлы в выбранной папке заменяются.

- `runs.csv`: итог каждой серии, время, число оценок, отклонение от ориентира.
- `history.csv`: лучшее значение после каждой генерации.
- `summary.json`: минимум, среднее, медиана, выборочное отклонение и максимум.
- `best.json`: координаты и начальное состояние лучшего запуска каждого метода.
- `reference.json`: независимый численный ориентир для разделимой функции.
- `*.svg`: графики, доступные без подключения к сети.

При своём `--output` отчёт создаётся как `REPORT.md` в родительской папке результата;
поэтому для отдельного опыта используйте отдельную родительскую папку.
