# Лабораторная № 3

Вариант 10, направление А: настройка малого классификатора по трём критериям.
Собственная реализация NSGA-II и сравнение с ГА взвешенной суммы.
Собственное обучение малой нейронной сети; NumPy используется для матриц.

Установка и запуск из корня репозитория:

```powershell
python -m pip install -r requirements.txt
python -m lab3.run
python -m lab3.run --config lab3/config.json --data lab3/data.csv --output lab3/results
```

Данные приложены в [data.csv](data.csv); отсутствующий файл создаётся по `data_seed`.
Параметры в [config.json](config.json). Каждый метод выполняет по 20 запусков;
в запуске 320 оценок и 960 реальных обучений. Работа занимает больше времени, чем
первые две, поскольку модель заново обучается при каждой оценке.

Отчёт: [REPORT.md](REPORT.md). Основные результаты:

- `runs.csv`, `summary.json`: статистика серии и ε-индикатор.
- `history.csv`: изменения лучшей ошибки и числа решений фронта по поколениям.
- `evaluations.jsonl`: все настройки, три измерения времени и цели каждой оценки.
- `final_fronts.json`, `pareto.json`, `pareto.csv`: финальные и объединённый фронты.
- `representatives.json`: три выбранных компромисса и испытательная точность.
- `model-*.json`: готовые веса и нормировка признаков.
- `pareto-*.svg`: три проекции фронта.

Время зависит от нагрузки компьютера. Для точного повторения исходной траектории
по записанным измерениям выполните:

```powershell
python -m lab3.replay --method nsga2 --seed 3000
python -m lab3.replay --method weighted --seed 3000
python -m lab3.predict --features 1.0 1.0 0.2 -0.4
```

Повторное проведение эксперимента заменяет результаты и отчёт. Отчёт создаётся
в родительской папке результатов; для отдельного опыта используйте отдельную папку.
