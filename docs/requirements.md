# Соответствие заданию

Индивидуальный вариант: N = 28, группа 517, Q = 1, Y = 26, V = 10.
Выполнены первые три лабораторные. Четвёртая и альтернативный симулятор
относятся к отдельным форматам задания и в этот комплект не включены.

| Требование | Где выполнено |
|---|---|
| Собственные эволюционные операторы | `evolab/ga.py`, `evolab/pareto.py`, `lab*/run.py` |
| Установка и примеры команд для каждой работы | `lab1/README.md`, `lab2/README.md`, `lab3/README.md` |
| Отчёт Markdown | `lab*/REPORT.md` |
| Вариант, пространство, цели и ограничения | Разделы постановки и модели в отчётах |
| Генотип и фенотип | Разделы представления в отчётах |
| Блок-схема | Схема Mermaid в каждом отчёте; GitHub отображает её графически |
| Параметры и критерий остановки | `lab*/config.json`, `lab*/results/environment.json` |
| Не менее 20 независимых запусков | 20 на метод; 60, 80 и 40 запусков по работам |
| Итоговые и поколенные таблицы | `lab*/results/runs.csv`, `history.csv` |
| Минимум, среднее, медиана, отклонение, максимум | `summary.json` и таблицы отчётов |
| Проверки алгоритмов и результатов | `tests/`, команда `python -m unittest discover -s tests -v` |
| Русские комментарии и пояснения | Исходные файлы, README и отчёты |
| Разделение изменений на коммиты | История Git, отдельный этап на каждую работу |

## Лабораторная № 1

| Требование | Реализация |
|---|---|
| Вещественное представление и не менее 30 особей | 9 координат, 60 особей |
| Отбор, скрещивание, мутация, границы, элитизм | Турнир, BLX-α, гауссовская мутация, отражение, две элитные особи |
| Одинаковый бюджет | 12000 оценок каждой конфигурации и случайной выборки |
| Смена одного фактора | Только закон масштаба мутации |
| График минимума, среднего, максимума | `convergence-*.svg` |
| Сравнение со случайной выборкой | `comparison.svg`, таблица отчёта |
| Ориентир глобального минимума варианта 10 | Ссылка на описание функции и собственный покоординатный численный ориентир |
| Дополнительное задание | BLX-α и убывающий масштаб мутации |

Убывающий масштаб зависит от бюджета; в отчёте он явно отличается от самоадаптации.
Численный ориентир не объявляется строгим доказательством.

## Лабораторная № 2

| Требование | Реализация |

## Лабораторная № 3

| Требование направления А | Реализация |
|---|---|
| Не менее двух противоречивых целей | Проверочная ошибка, измеренное время, число параметров |
| Собственный NSGA-II | `evolab/pareto.py` |
| Недоминируемая сортировка и разнообразие | Ранги Парето и нормированное расстояние до скопления |
| Новое относительно первых работ | Многокритериальный элитный отбор |
| Несколько проекций трёхмерного фронта | Три файла `pareto-*.svg` |
| Три характерных решения | `representatives.json`, таблица отчёта, три сохранённые модели |
| Сравнение со взвешенной суммой | По 20 запусков с одинаковым бюджетом 320 оценок |
| Анализ компромиссов | ε-индикатор, точность, цена и ограничения измерения времени |
| Повторение стохастического поиска | Управляемые генераторы, полный журнал и `lab3/replay.py` |

Выбрано направление А. В исходном задании два направления перечислены для каждого
варианта без дополнительной формулы выбора; при наличии отдельного указания
преподавателя выбор нужно сверить с ним.
