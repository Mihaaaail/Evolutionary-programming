# Подключение репозитория к GitHub

Проект уже является локальным репозиторием Git с веткой `main` и отдельными
коммитами по этапам работы. Для публикации нужен репозиторий в твоём аккаунте GitHub.

1. Создай на GitHub пустой репозиторий, например `evolution-labs`.
2. Выбери доступ по требованиям преподавателя. Публичный доступ удобен для просмотра;
   при закрытом доступе преподавателю потребуется приглашение.
3. При создании не добавляй README, лицензию и .gitignore: файлы уже есть локально.
4. Скопируй адрес репозитория и передай его в этот чат. Подключение и отправку
   можно выполнить следующим шагом, сохранив всю историю изменений.

Если отправляешь самостоятельно, открой PowerShell в папке проекта и выполни:

```powershell
git remote add origin https://github.com/ИМЯ_АККАУНТА/evolution-labs.git
git push -u origin main
```

В команде нужно заменить `ИМЯ_АККАУНТА` и название репозитория своим настоящим адресом.
При первом подключении Git может предложить войти в аккаунт через браузер.
После отправки на GitHub будут видны три папки лабораторных, отчёты, графики,
результаты опытов и история коммитов.

Для последующих изменений:

```powershell
git status
git add ИЗМЕНЁННЫЕ_ФАЙЛЫ
git commit -m "Кратко описать изменение по-русски"
git push
```

Если репозиторий на GitHub уже содержит собственные коммиты, не выполняй
принудительную отправку: сначала нужно согласовать две истории.
