# Проверка комплекта

Проверка выполнена 14 октября 2026 года в Windows на Python 3.14.0 и NumPy 2.3.5.
Полные сведения о среде и параметрах приложены к каждой серии в `environment.json`.

## Реально проведённые серии

| Работа | Методов | Запусков на метод | Всего запусков | Оценок на запуск |
|---|---:|---:|---:|---:|
| № 1 | 3 | 20 | 60 | 12000 |
| № 2 | 4 | 20 | 80 | 3000 |
| № 3 | 2 | 20 | 40 | 320 |

В третьей работе каждая оценка включает три обучения: всего 38400 обучений
для двух серий поиска. Дополнительное обучение трёх выбранных моделей,
линейная модель и разогрев не входят в сравнительный бюджет поиска.

## Проверки

22 автоматические проверки завершились успешно. Проверены:

- точный бюджет, включая неполные поколения;
- повторение поиска при одном начальном состоянии генератора;
- значения функции в известных точках и численный ориентир двумерного случая;
- обработка больших выходов за границы;
- каждый вид жёстких ограничений расписания;
- восстановление допустимости после обеих дискретных мутаций;
- корректность ручных примеров доминирования, расстояний и ε-индикатора;
- разделение обучающих, проверочных и испытательных данных;
- совпадение сохранённых весов с опубликованной точностью;
- полнота серий и одинаковые бюджеты сравниваемых методов.

Отдельно повторены **все 40** траекторий третьей работы по журналу измерений.
Финальные фронты совпали с сохранёнными. Проверены все внутренние ссылки в Markdown.
Все 13 графиков SVG преобразованы в изображения и осмотрены: подписи читаются,
легенды помещаются, точки и кривые не обрезаны. Для второй работы добавлен отдельный
график второй половины поиска, чтобы большие начальные штрафы не скрывали различия методов.

Автоматические проверки можно повторить без изменения материалов:

```powershell
python -m unittest discover -s tests -v
```

На другой системе фактическое время обучения изменится. Точная траектория исходного
поиска воспроизводится по приложенному журналу; сравнение новых измерений следует
проводить в одинаковой среде. Автоматическая проверка на GitHub настроена в
`.github/workflows/checks.yml`; её первый удалённый запуск произойдёт после публикации.
