# Лабораторные работы по эволюционному программированию

Общий репозиторий для лабораторных № 1, № 2 и № 3 по заданию Р. В. Душкина.
Индивидуальные параметры: N = 28, группа 517, Q = 1, Y = 26.
Вариант V = 1 + ((17 · 28 + 7 · 1 + 26) mod 20) = **10**.

Алгоритмы и генетические операторы реализуются в исходном коде проекта.
Готовые библиотеки оптимизации не используются. Отчёты предоставляются в Markdown.

## Требования

Python 3.11 или новее. Для третьей работы нужна NumPy, указанная в requirements.txt.
Первые две работы используют только стандартную библиотеку Python.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Далее команды выполняются из корня репозитория. Вместо `python` можно использовать
`.venv\Scripts\python`; включать окружение в PowerShell необязательно.

## Состав

- [Лабораторная № 1](lab1/README.md): минимизация функции Михалевича, d = 9.
- [Лабораторная № 2](lab2/README.md): составление плана дежурств на неделю.
- [Лабораторная № 3](lab3/README.md): многокритериальная настройка классификатора.
- `evolab/`: общие алгоритмы, статистика и автономные графики.
- `tests/`: проверки операторов, ограничений и математических свойств.
- `variant.json`: исходные параметры индивидуального варианта.

## Запуск

```powershell
python -m lab1.run
python -m lab2.run
python -m lab3.run
python -m unittest discover -s tests -v
python run_all.py
```

Команды `lab1.run`, `lab2.run` и `lab3.run` проводят полные серии опытов.
Результаты сохраняются в отдельной
папке работы. Графики SVG открываются браузером без доступа к сети.

`run_all.py` последовательно повторяет все опыты и проверки; отдельная команда
проверок не изменяет результаты. Для начального ознакомления достаточно уже
приложенных отчётов и таблиц.

## Проведённые опыты

Выполнены 60, 80 и 40 запусков по трём работам. Каждый сравниваемый метод получил
одинаковый бюджет внутри своей лабораторной. Комментарии, пояснения и подписи по-русски.

| Работа | Основной результат |
|---|---|
| № 1 | Лучшее значение ГА −8,6225355512, численный ориентир −8,6601517156; среднее убывающего масштаба −8,2666064763 против −4,4743953727 у случайной выборки |
| № 2 | Лучшее допустимое расписание: стоимость 64; жадная эвристика 73; все итоговые решения допустимы |
| № 3 | Точность выбранной модели на испытательных данных 87,5%; линейная модель 68,75%; общий эмпирический фронт из 26 настроек |

Это наблюдаемые результаты приложенных серий; подробный разброс и ограничения
сравнений описаны в отчётах. В третьей работе измерение времени может менять
траекторию нового запуска; исходная траектория точно повторяется по журналу.
